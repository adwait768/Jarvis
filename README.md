# JARVIS v1

A free starter Android personal assistant made for Adwait.

## Current features
- JARVIS dark interface
- Voice input using Android SpeechRecognizer
- Voice replies using Android TextToSpeech
- Basic commands: time, date, greetings
- Open YouTube
- Google search
- Text chat

## Build
Open the project in Android Studio or another compatible Gradle Android environment.

For a phone-only workflow, the included GitHub Actions workflow can build the debug APK after the project is uploaded to a GitHub repository. Run:
Actions → Build JARVIS APK → Run workflow.

The generated APK is uploaded as an artifact named JARVIS-debug-apk.
